# 賽博靈骨塔 Cyber Columbarium

> Ctrl+Z won't bring you back.

一座線上的賽博靈骨塔：朋友的照片封在漂浮的肥皂泡裡，想到時可以上去上香、敲木魚累積功德、留言，塔主本人也能認領塔位並回覆。

## 主要功能

- **泡泡塔位**：照片放進會變形、漂浮的透明泡泡，大小與位置隨機分布。
- **上香**：插香動畫、香會隨時間燒短；插滿 10 支後開始累積香灰，15 分鐘滿出來即可收集保平安。
- **香火等級**：香火漸旺 → 興旺 → 鼎盛 → 萬家香火，越旺越華麗。
- **敲木魚**：金光粒子、連擊計數、佛光，連擊 10 / 33 / 66 / 108 下有里程碑特效；隨機掉落「好運 +1」「煩惱 −1」等運勢。
- **我的福袋**：收藏平安香灰與運勢值。
- **神明巡塔**：每 5 分鐘一位神明降臨，財神爺、福神、土地公加功德；衰神、窮神、惡魔偷香灰與運勢。
- **塔主功能**：認領塔位、更換頭貼／名稱／個性簽名、24 小時首頁便利貼、回覆留言。
- **通知與跑馬燈**：鈴鐺通知誰來過；頂部 LED 跑馬燈由網站擁有者發布。

## 執行環境

本頁面為 Claude Artifact，資料儲存、登入身分等功能使用 claude.ai 提供的執行環境（`window.claude` 的 `db`、`user` 能力）。直接以瀏覽器開啟 `index.html` 或部署到 GitHub Pages 時，畫面可以顯示，但無法讀寫資料（上香、留言等功能將停用）。

若要在 claude.ai 以外運作，需要將資料層改接其他後端服務（例如 Firebase、Supabase）。
